# QUALITY-01 去水印画质基准

版本 1 包含 30 个固定合成样本。渐变、砖墙、纹理、标牌和人像示意图各配半透明文字、重复文字、倾斜文字、图标、不透明文字和无水印对照。遮罩由合成时的透明度生成，精确标记水印覆盖区域。实拍和自动检测评测待补充。

启动后端并准备 LaMa 和 FLUX Fill 权重。完整对比需要 CUDA。使用项目的 Python 环境，在仓库根目录运行下面的命令。每次运行指定一个新的输出目录。

```sh
python -m scripts.benchmark_watermark_quality --output /tmp/hiimage-quality-v1
```

默认用同一份图片和遮罩调用两个模型，遮罩扩张为 0。FLUX Fill 固定提示词、引导强度 15、随机种子 42 和 30 步。用 `--sample brick-translucent` 缩小范围，用 `--steps 2` 做快速冒烟，用 `--models wm_lama` 在 CPU 上单独跑 LaMa。后端地址可通过 `--base-url` 指定。

每个样本目录保存原图、带水印图、遮罩及模型输出。报告记录输入像素哈希、模型参数、耗时、遮罩内平均绝对误差和遮罩外改动像素数。平均误差以无水印原图为参照，仍需并排查看纹理、文字和人脸细节。空遮罩样本标记为跳过。接口失败、输出尺寸变化或遮罩外像素变化会使脚本以非零状态退出，已得到的结果仍会写入报告。
