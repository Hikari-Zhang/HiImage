## 1. 产品概述

### 1.1 产品定位

HiImage 是一款 AI 驱动的图像处理桌面工具，面向设计师、内容创作者和个人用户。提供去水印、抠图、超分辨率、图片降噪、智能合成核心功能，基于 Electron + FastAPI 构建，支持本地和远程两种运行模式。去水印 / 降噪 / 超分 / 合成共享工作图，便于同一张图连续处理。所有模型配置统一在 `backend/core/models.yaml` 维护，新增模型无需修改代码。

### 1.2 目标用户

| 用户群体 | 典型场景 |
|----------|----------|
| 个人用户 | 处理个人照片上的时间戳水印、平台水印 |
| 设计师 / 创作者 | 处理素材图片、提升低分辨率素材清晰度 |
| 内容运营 | 批量处理营销素材图片 |
| 开发者 | 自部署后端服务，集成到自有工作流 |

### 1.3 产品目标

- **易用性**：三步完成水印去除（打开 → 选区 → 处理）
- **高质量**：基于 `models.yaml` 驱动的 30+ 个 AI 模型，覆盖各类场景
- **批量处理**：支持一次性导入多张图片，逐张处理，实时进度反馈
- **灵活部署**：支持本地运行和远程 Docker 部署
- **可扩展**：`models.yaml` 驱动架构，新增模型只需添加配置，无需修改代码
- **稳定性**：后端进程可靠管理，退出时干净清理资源

### 2.2 去水印 (Watermark Removal)

#### 功能描述

用户加载图片后，通过手动框选或自动检测标记水印区域，选择 AI 模型执行修复，获得去除水印后的图片。

#### 功能点

| # | 功能 | 优先级 | 描述 |
|---|------|--------|------|
| F1 | 图片加载 | P0 | 支持拖拽 / 文件对话框打开图片（PNG/JPG/BMP/WebP/TIFF） |
| F2 | ROI 绘制 | P0 | 鼠标拖拽在画布上绘制矩形选区，支持缩放/平移画布 |
| F3 | ROI 管理 | P0 | 列表展示所有选区，支持多选删除、清空所有 |
| F4 | 自动检测 | P1 | 基于 CV 算法自动识别水印位置，敏感度可调 |
| F5 | 模型选择 | P0 | 分组下拉选择模型（快速修复 / 专用模型 / 扩散模型） |
| F6 | 执行修复 | P0 | 点击按钮开始处理，显示实时进度条 |
| F7 | 结果预览 | P1 | 前后对比滑块 (Before/After) |
| F8 | 保存结果 | P0 | 通过系统对话框保存为 PNG/JPG |

#### 支持的模型

**快速修复（本地推理，无需下载，CLI 模式）**

| 模型 | 特点 | 显存需求 |
|------|------|----------|
| LaMa（推荐·通用） | 综合最佳，速度快 | ~500MB，无需显卡 |
| MiGAN（GAN·快速） | 规则纹理背景效果好 | ~600MB，无需显卡 |
| ZITS（边缘感知） | 边缘清晰 logo 效果好 | ~700MB，无需显卡 |
| FCF（快速填充） | 背景简单/重复时效果佳 | ~600MB，无需显卡 |
| MAT（精细修复） | 质量最高但速度较慢 | ~1.5GB，无需显卡 |
| LDM（轻量扩散） | 质量与速度均衡 | ~1.5GB，无需显卡 |
| Manga（漫画专用） | 线条清晰无模糊 | ~500MB，无需显卡 |
| CV2（传统算法） | 速度最快，质量有限 | <100MB，纯 CPU |

**专用 / 扩散模型（首次使用自动下载，HTTP Server 保活模式）**

| 模型 | 特点 | 显存需求 |
|------|------|----------|
| AnyText（推荐·文字水印） | 文字水印专用，识别字体后重建 | ~10GB 统一内存 |
| PowerPaint V1（通用最强） | 支持文字引导，综合效果最强 | ~12GB 统一内存 |
| SD 1.5 Inpainting（通用） | 复杂/渐变背景效果自然 | ~8GB 统一内存 |
| Realistic Vision V5.1（写实） | 写实照片/人像真实感最强 | ~8GB 统一内存 |
| DreamShaper（艺术） | 艺术感强，插画/幻想场景 | ~8GB 统一内存 |
| Anything V4（动漫） | 二次元/动漫/CG 插图专用 | ~8GB 统一内存 |
| SDXL Inpainting（高分辨率） | 2K+ 图像细节最佳 | ~16GB 统一内存 |

| F13 | 批量处理 | P0 | 导入多张图片，逐张处理，实时更新 UI 进度 |
| F14 | 对比预览 | P1 | 拖拽滑块对比原图与超分结果 |
| F15 | 保存结果 | P0 | 单张保存 / 批量输出到指定目录 |

#### 批量处理详细需求

| # | 功能 | 描述 |
|---|------|------|

### 2.4 图片降噪 (Denoise)

#### 功能描述

用户加载带压缩噪声或颗粒的图片，选择降噪模型，生成**与输入相同分辨率**的结果。支持单张与批量。默认 SCUNet 盲去噪；另有 NAFNet（相机）、SwinIR（JPEG）、以及 Real-ESRGAN 快速清晰化。

#### 功能点

| # | 功能 | 优先级 | 描述 |
|---|------|--------|------|
| D1 | 图片加载 | P0 | 同超分：拖拽 / 文件对话框；单张写入共享工作区 |
| D2 | 模型选择 | P0 | 按噪声类型分组：盲去噪 / 观感 / 相机 ISO / 去压缩 / 快速清晰化 |
| D3 | 单张处理 | P0 | 进度显示；输出尺寸等于输入 |
| D4 | 批量处理 | P0 | 导入多张，一次请求逐张处理，模型只加载一次 |
| D5 | 对比预览 | P1 | 拖拽滑块对比处理前后 |
| D6 | 保存结果 | P0 | 单张 `{原名}_denoised.png` / 批量输出到指定目录 |

#### 支持的模型

| 类别 | 模型 ID | 适合 | 大小 |
|------|---------|------|------|
| 照片 / 截图 | denoise-scunet-psnr（推荐） | 盲去噪，保纹理 | 72MB |
| 观感更干净 | denoise-scunet-gan | 更干净，可能抹纹理 | 72MB |
| 相机 ISO | denoise-nafnet-sidd | 手机 / 相机噪声 | 117MB |
| 去压缩伪影 | denoise-swinir-jpeg | JPEG 色块 / 振铃 | 98MB |
| 快速清晰化 | denoise-general / denoise-anime | 超分权重复用，偏锐化 | 5MB / 18MB |

### 2.5 抠图 (Cutout)

#### 功能描述

用户加载图片后选择抠图模型，得到带透明通道的结果；可用画笔增减前景，并调节羽化 / 膨胀后合成到自定义背景。抠图使用独立图像状态，不并入去水印/超分/合成工作区。

#### 功能点

| # | 功能 | 优先级 | 描述 |
|---|------|--------|------|
| C1 | 图片加载 | P0 | 拖拽 / 文件对话框 |
| C2 | 一键抠图 | P0 | BiRefNet / rembg 等，返回 RGBA + alpha mask |
| C3 | 画笔精修 | P0 | 增加/擦除前景 |
| C4 | 羽化 / 膨胀 | P1 | 边缘平滑与收缩扩张 |
| C5 | 背景合成 | P1 | 合成到自定义纯色背景 |
| C6 | 保存 | P0 | 保存 PNG（含透明） |

### 2.6 智能合成 (Smart Synthesis)

#### 功能描述

智能合成模块支持 **7 种合成模式**，底层由 `models.yaml` 统一驱动，覆盖从自动服装换色到自由指令编辑的广泛场景。

#### 模式总览

| 模式 ID | 名称 | 交互方式 | 后端技术 | 推荐场景 |
|---------|------|----------|----------|----------|
| `background_replace` | 换背景 | 上传背景图 | rembg 抠图 + 合成 | 商品图/人像换背景 |
| `outfit_swap` | 换装模拟 | 上传服装图 + 选 ROI | Inpainting 纹理替换 | 试穿上衣/裤子 |
| `face_swap` | 换脸模拟 | 上传人脸图 + 选 ROI | GFPGAN + 叠覆合成 | 人脸替换模拟 |
| `virtual_tryon` | 虚拟试穿 | 上传服装图 | 参考图引导 Inpainting | 在线试衣间 |
| `prompt_inpaint` | 精准替换 | 框选 ROI + 输入描述 | SD 1.5 / SDXL / FLUX Inpainting | 指定区域按描述重绘 |
| `auto_segment_edit` | 智能定位编辑 | 输入中文指令 | 自动分割 + 换色/换风格 | "将上衣换成红色" |
| `instruction_edit` | 自由编辑 | 输入任意指令 | InstructPix2Pix / FLUX | "把白天变成黄昏" |

#### 抠图模型（换背景用，rembg 管理）

## 4. 技术架构

### 4.1 模型驱动架构

所有模型配置集中在 `backend/core/models.yaml`，代码通过 `model_registry.py` 读取，实现**配置与代码分离**：

- 新增模型只需在 `models.yaml` 添加一条记录
- 无需修改任何 Python / TypeScript 代码
- 支持多种 provider：IOPaint / diffusers / rembg / facexlib / realesrgan / HiImage（组合管道）
- 支持 `supported_params` 字段为各模型定义推理参数（步数、guidance scale 等）

### 4.2 系统架构

## 8. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 大模型下载慢 | 首次使用体验差 | 提供 HF Mirror 选项 + 下载进度显示 |
| MPS 内存不足 | 大图处理失败 | 自动降级到 CPU + 分块处理 |
| Docker GPU 兼容 | 特定显卡不支持 | 提供 CPU fallback 配置 |
| 模型更新 | 版本不兼容 | 模型版本锁定（requirements-locked.txt）|
| 端口被占用 | 重启应用失败 | 启动前自动清理残留进程 |
| 竞态条件 | 快速操作导致状态错误 | 串行队列保证操作顺序 |
| macOS 打包分发 | $99/年 Apple Developer 证书 | 暂不签名打包，仅自己使用 |

### A. 术语表

| 术语 | 说明 |
|------|------|
| ROI | Region of Interest，用户标记的水印区域 |
| Inpainting | 图像修复，将水印区域重建为正常背景 |
| Super Resolution | 超分辨率，通过 AI 放大图像并增强细节 |
| IOPaint | 开源图像修复框架，支持多种模型 |
| Real-ESRGAN | 超分辨率模型，支持 2x/4x 放大 |
| 图片降噪 | 保持分辨率的 AI 去噪；默认 SCUNet，清晰化档复用 Real-ESRGAN outscale=1 |
| MPS | Metal Performance Shaders，Apple 芯片 GPU 加速 |
| Dilation | 遮罩扩张，让遮罩略大于 ROI 确保完全覆盖水印边缘 |
| 进程组 | macOS/Linux 下相关进程的集合，可一次性批量终止 |
| models.yaml | 统一模型注册表，所有功能模块从此文件读取模型配置 |
