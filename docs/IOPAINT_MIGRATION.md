## 后续模型适配范围

机器约定中的 models.keep（33 条）、models.retire（15 条）和 target_defaults 是删除前冻结的未来适配目标，不是当前可用注册表。当前以 current_model_ids（23 条）和 removed_model_ids（25 条）为准。wm_lama 已原生恢复。未来是否恢复旧 ID，必须先完成独立实现和功能验收；不能仅修改 provider。

拟适配 LaMa、OpenCV、SD1.5 Inpaint、SDXL Inpaint、FLUX Fill 五条路线。抠图、超分及其他独立实现继续保留。PowerPaint、AnyText、MAT、ZITS 等首版不恢复；不自动下载更大的模型充当替代品。

CPU、CUDA、macOS MPS 分别验证 dtype、算子与内存，未验收不声明支持。FLUX 首版不承诺 MPS；LaMa 在 MPS 未验证前优先 CPU。FLUX Fill 已使用专用管线并通过 Windows CUDA 的尺寸、参数与出图冒烟。页面已接入提示词、随机种子、步数和引导强度。复杂纹理的样本结果记录在优化进度。

## 必须保留的硬超时

新修复执行器采用同一 Python 环境内受监督子进程，每请求一个 worker；全局最多一个活动 worker。主服务在创建进程前计算单调时钟截止时间，覆盖加载、预处理、全部分区、推理、后处理和结果传回；排队等待及模型下载不计入。分区和阶段不能重置总预算，worker 内不下载模型。

快速路线默认 300 秒，生成式路线 1800 秒。到期不额外等待，回收整个进程树；用户取消允许 0.5 秒协作退出，清理总等待最多 5 秒。Windows 在用户代码执行前纳入独立 Job，POSIX 使用独立进程组。确认进程退出后才释放推理槽和资源许可，回收失败则阻止后续推理，直至确认退出或重启。

超时返回 504 INFERENCE_TIMEOUT、任务 failed，不自动重试；回收失败返回 503 INFERENCE_CLEANUP_FAILED。Future 取消不能替代实际底层进程终止。详细字段以机器约定为准。
